# 🏦 ApexCore Banking System

ApexCore Banking System is a full-stack digital banking management application designed to simplify and manage modern banking operations.

## ✨ Features

- 🔐 Secure Authentication & Role-Based Access
- 👤 Customer Management
- 💳 Savings & Current Account Management
- 💰 Deposits & Withdrawals
- 🔄 Money Transfers
- 📊 Transaction History
- 🏠 Doorstep Deposit & Withdrawal Services
- 👨‍💼 Employee Management
- 👨‍💼 Employee Head Management
- 📍 Doorstep Request Assignment & Tracking
- 🛡️ Admin Dashboard & Complete Workflow Monitoring
- 💵 Overall Bank Balance Monitoring
- 🔔 Notifications & Status Tracking
- 📋 Audit & Activity Tracking
- 🔥 Firebase/Firestore Integration

## 👥 User Roles

- **Admin** – Complete control and visibility of the banking system
- **Employee Head** – Manages employees and doorstep service assignments
- **Employee** – Handles assigned/available doorstep requests
- **Customer** – Manages accounts, transactions, transfers, and doorstep services

## 🛠️ Technologies

- React
- JavaScript/TypeScript
- Firebase
- Cloud Firestore
- Firebase Authentication
- HTML & CSS

## 🎯 Project Goal

To provide a secure, user-friendly digital banking platform that connects customers, bank employees, employee heads, and administrators while supporting both online banking and doorstep banking services.
